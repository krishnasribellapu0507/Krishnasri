# Krishnasri — Cinematic Portfolio V3

This folder contains the latest cinematic, single-page developer portfolio from 17 November 2026.

## Preview
Open `index.html` in a browser, or deploy this folder using Netlify Drop: https://app.netlify.com/drop

## Required image
The page references `anime-developer.png` in the same directory. **Upload the original `anime-developer.png` from the downloadable portfolio ZIP into this folder** before deploying. The image is not included in this GitHub commit because the GitHub integration only accepted text content in this workflow.

## Features
- Cinematic intro and editorial hero
- Animated background and cursor-responsive effects
- Animated technical skills
- TaskFlow, CodeLab, RepoLens browser demos
- Responsive layouts and reduced-motion support

## Accuracy
Project demos are educational prototypes, not claims of professional client work. Before sharing with employers, update contact placeholders and verify all links.
